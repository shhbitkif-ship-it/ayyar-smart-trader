# عیار هوشمند | Ayyar Smart Trader

اپلیکیشن اندروید و API تحلیل بازار طلا برای بازار ایران و جهانی. هدف، نمایش دادهٔ واقعی و قابل ردیابی است؛ قیمت یا سیگنال ساختگی تولید نمی‌شود.

## دامنهٔ محصول
- بازار ایران: طلای ۱۸ و ۲۴ عیار، مظنه آبشده، سکه امامی، نیم‌سکه، ربع‌سکه و دلار آزاد.
- بازار جهانی: اونس طلا XAU/USD.
- وضعیت سیگنال: BUY / SELL / WAIT / NO_TRADE؛ تا وقتی داده و کنترل ریسک تأیید نشده‌اند، سفارش اجرایی فعال نمی‌شود.
- ریسک پیش‌فرض هر معامله حداکثر ۱٪ سرمایه، سقف زیان روزانه ۳٪ و افت سرمایه ۸٪.
- معاملهٔ واقعی و اتصال به بروکر فعلاً غیرفعال است.

## منبع داده
- منبع فعلی: NerkhAra، فایل JSON عمومی بدون API Key: https://nerkhara.com/api/v1/latest.json
- دادهٔ منبع حدود هر ۱۰ دقیقه به‌روزرسانی می‌شود؛ این نرخ‌ها قیمت شاخصی هستند، نه قیمت اجرایی بروکر.
- قیمت قدیمی یا نامعتبر به‌عنوان LIVE نمایش داده نمی‌شود و در صورت قطع منبع، قیمت ساختگی تولید نمی‌شود.
- قرارداد مستند منبع: آرایهٔ `items`، شناسهٔ `id`، قیمت `price`، واحد `unit`، زمان `updated_utc` و پرچم `stale` است.
- واحد مورد انتظار برای نمادهای بازار ایران `IRT` (تومان) و برای `xau` برابر `USD` (دلار به‌ازای اونس تروا) است؛ بک‌اند در صورت مغایرت واحد، قیمت را غیرقابل استفاده علامت می‌زند.
- زمان هر قیمت و نام منبع باید در رابط کاربری نمایش داده شود. NerkhAra را به‌عنوان منبع ذکر کنید و به https://nerkhara.com پیوند بدهید.
- مستندات منبع بررسی شده‌اند، اما دریافت زندهٔ JSON از محیط استقرار و تطبیق نهایی داده‌ها هنوز باید پس از Deploy انجام شود.

## API
- سلامت: GET /health
- قیمت‌ها: GET /v1/market/quotes
- وضعیت بازار: GET /v1/market/status
- سیاست ریسک: GET /v1/risk/policy
- محاسبه حجم: POST /v1/risk/position-size
- ارزیابی تحلیل: POST /v1/signals/evaluate
- مستندات: /docs

## API رایگان مستقرشده روی Cloudflare Workers
- آدرس پایه: `https://ayyar-smart-trader-api.ayyar-smart-trader.workers.dev`
- سلامت: [`/health`](https://ayyar-smart-trader-api.ayyar-smart-trader.workers.dev/health)
- قیمت‌ها: [`/v1/market/quotes`](https://ayyar-smart-trader-api.ayyar-smart-trader.workers.dev/v1/market/quotes)
- وضعیت بازار: `/v1/market/status`
- سیاست ریسک: `/v1/risk/policy`
- کد Worker در `cloudflare/worker.js` نگهداری می‌شود.
- این Worker از فید عمومی NerkhAra استفاده می‌کند؛ هیچ کلید API در برنامه یا مخزن قرار نگرفته است.

## اندروید
پوشهٔ `android` پروژهٔ Android Studio است. GitHub Actions فایل Debug APK را با نام `ayyar-smart-trader-debug-apk` به‌صورت Artifact می‌سازد. نشانی API رایگان Cloudflare Workers در تنظیمات پیش‌فرض برنامه قرار گرفته است.

## ساخت و آزمون خودکار
با هر push به شاخهٔ `main`، GitHub Actions تست‌های بک‌اند و ساخت APK آزمایشی Debug را اجرا می‌کند.

## محدودیت‌ها و ایمنی
- API و اپلیکیشن ابزار اطلاعاتی/تحلیلی هستند، نه توصیه مالی.
- اتصال به کارگزاری و ثبت سفارش واقعی پیاده‌سازی نشده است.
- Snapshot ده‌دقیقه‌ای برای معاملات سریع یک‌دقیقه‌ای کافی نیست؛ تا دریافت داده کندلی معتبر، خروجی باید محافظه‌کارانه باشد.
- ساختار JSON و قرارداد منبع بر اساس مستندات رسمی NerkhAra پیاده‌سازی شده است؛ سلامت Worker باید با endpointهای بالا بررسی شود و وضعیت هر نرخ فقط در صورت تازه و معتبر بودن LIVE خواهد بود.


### نکتهٔ راه‌اندازی Vercel
در صفحهٔ Import، اگر فهرست فایل‌ها خالی بود یا تشخیص FastAPI انجام نشد، Root Directory را دقیقاً روی `backend` تنظیم کن؛ فایل `index.py` در همان پوشه نقطهٔ ورود ASGI است. پس از اولین Deploy، URL واقعی Vercel را برای تنظیم نسخهٔ نهایی APK نگه دار.
