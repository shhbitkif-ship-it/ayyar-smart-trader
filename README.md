# عیار هوشمند | Ayyar Smart Trader

اپلیکیشن اندروید و بک‌اند تحلیل بازار طلا برای بازار جهانی و ایران. هدف، ابزار عملیاتی با دادهٔ واقعی و قابل ردیابی است؛ قیمت یا سیگنال ساختگی تولید نمی‌شود.

## دامنهٔ محصول
- بازار جهانی: XAU/USD و اونس طلا.
- بازار ایران: طلای ۱۸ و ۲۴ عیار، مظنه آبشده، سکه امامی، نیم‌سکه، ربع‌سکه و دلار تهران.
- تایم‌فریم‌های تحلیل: ۱، ۵، ۱۵ و ۳۰ دقیقه، ۱ و ۴ ساعت و روزانه.
- تحلیل تکنیکال در حال توسعه: EMA 20/50/100/200، RSI، MACD، Bollinger Bands، ATR، VWAP در صورت وجود حجم، حمایت/مقاومت و فیبوناچی؛ به‌علاوهٔ تأیید چندتایم‌فریمی.
- وضعیت سیگنال: BUY / SELL / WAIT / NO_TRADE؛ تا وقتی داده، نقدشوندگی، مشخصات قرارداد، اسپرد و کنترل ریسک تأیید نشده‌اند، سفارش اجرایی و قیمت ورود/حدضرر/اهداف فعال نمی‌شوند.
- سیاست ریسک: حداکثر ۱٪ ریسک پیش‌فرض هر معامله، سقف زیان روزانه ۳٪ و افت سرمایه ۸٪؛ محاسبهٔ حجم فقط با مشخصات تأییدشدهٔ قرارداد انجام می‌شود.
- معاملهٔ واقعی و اتصال به بروکر فعلاً غیرفعال است. مدل ML تا زمان وجود دادهٔ تاریخی معتبر، بک‌تست خارج از نمونه و ارزیابی ریسک، سیگنال عملیاتی تولید نمی‌کند.

## منابع داده
- بازار ایران: Talasanj API؛ قیمت‌ها به تومان و با timestamp منبع. کلید باید فقط در Environment سرور قرار گیرد.
- اونس جهانی: Metals.Dev؛ در صورت نبود کلید آن، اونس دریافت‌شده از Talasanj به‌عنوان fallback با برچسب منبع مشخص استفاده می‌شود.
- دادهٔ قدیمی، بدون timestamp یا نامعتبر با وضعیت STALE/UNAVAILABLE برچسب می‌خورد و برای سیگنال مجاز نیست.

## اجرای بک‌اند
از مسیر backend:

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
export TALASANJ_KEY="..."
export METALS_DEV_KEY="..."  # optional; Talasanj ounce is fallback
PYTHONPATH=. uvicorn app.main:app --reload
```

- سلامت: GET /health
- قیمت‌ها: GET /v1/market/quotes
- وضعیت بازار: GET /v1/market/status
- سیاست ریسک: GET /v1/risk/policy
- محاسبه حجم: POST /v1/risk/position-size
- ارزیابی تحلیل: POST /v1/signals/evaluate
- مستندات: /docs

## استقرار Render
فایل render.yaml سرویس وب FastAPI را تعریف می‌کند. پس از ساخت سرویس از روی Blueprint، کلیدهای TALASANJ_KEY و در صورت استفاده METALS_DEV_KEY را در Environment سرویس وارد کنید. کلید واقعی را در GitHub یا داخل APK قرار ندهید.

## اندروید
پوشه android پروژهٔ Android Studio است. اپ از API بک‌اند می‌خواند و منبع/وضعیت هر قیمت را نمایش می‌دهد. آدرس API در android/app/build.gradle.kts از طریق API_BASE_URL تنظیم می‌شود.

## ساخت و آزمون خودکار
GitHub Actions تست‌های بک‌اند و ساخت APK آزمایشی Debug را انجام می‌دهد و خروجی را با نام ayyar-smart-trader-debug-apk به‌صورت Artifact منتشر می‌کند. نسخهٔ Release امضاشده پس از تنظیم امن کلید امضا ساخته خواهد شد.

## وضعیت فعلی و محدودیت‌ها
- هستهٔ بک‌اند، آداپتورهای داده، سیاست ریسک و رابط اولیهٔ اندروید در مخزن ثبت شده‌اند.
- سرویس Render و کلیدهای API هنوز باید در محیط میزبانی پیکربندی شوند.
- تا پیش از تأیید منابع و دریافت دادهٔ کافی، خروجی درست موتور تحلیل NO_TRADE است.
- سورس و تنظیمات توسعه در حال تکمیل‌اند؛ هیچ‌گاه خروجی CI ناموفق را APK آمادهٔ نصب تلقی نکنید.
