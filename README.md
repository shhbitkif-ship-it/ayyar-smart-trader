# عیار هوشمند | Ayyar Smart Trader

اپلیکیشن اندروید و API تحلیل بازار طلا برای بازار ایران و جهانی. هدف، ابزار عملیاتی با دادهٔ واقعی و قابل ردیابی است؛ قیمت یا سیگنال ساختگی تولید نمی‌شود.

## دامنهٔ محصول
- بازار جهانی: XAU/USD و اونس طلا.
- بازار ایران: طلای ۱۸ و ۲۴ عیار، مظنه آبشده، سکه امامی، نیم‌سکه، ربع‌سکه و دلار آزاد تهران.
- تایم‌فریم‌های موتور تحلیل: ۱، ۵، ۱۵ و ۳۰ دقیقه، ۱ و ۴ ساعت و روزانه.
- تحلیل تکنیکال: EMA 20/50/100/200، RSI، MACD، Bollinger Bands، ATR، VWAP در صورت وجود حجم، حمایت/مقاومت و فیبوناچی؛ به‌علاوهٔ تأیید چندتایم‌فریمی.
- وضعیت سیگنال: BUY / SELL / WAIT / NO_TRADE؛ تا وقتی داده، نقدشوندگی، مشخصات قرارداد، اسپرد و کنترل ریسک تأیید نشده‌اند، سفارش اجرایی و قیمت ورود/حدضرر/اهداف فعال نمی‌شوند.
- سیاست ریسک: حداکثر ۱٪ ریسک پیش‌فرض هر معامله، سقف زیان روزانه ۳٪ و افت سرمایه ۸٪؛ محاسبهٔ حجم فقط با مشخصات تأییدشدهٔ قرارداد انجام می‌شود.
- معاملهٔ واقعی و اتصال به بروکر فعلاً غیرفعال است. مدل ML تا زمان وجود دادهٔ تاریخی معتبر، بک‌تست خارج از نمونه و ارزیابی ریسک، سیگنال عملیاتی تولید نمی‌کند.

## منابع قیمت بدون کلید
- بازار ایران و اونس جهانی: NerkhAra، فایل JSON عمومی بدون ثبت‌نام و API Key.
- نرخ‌های منتشرشده هر ۱۰ دقیقه به‌روزرسانی می‌شوند؛ API حداکثر یک دقیقه در خود Worker کش می‌شود.
- قیمت‌ها همراه timestamp، وضعیت stale، تعداد منابع و spread منتشر می‌شوند.
- واحد IRT در API منبع به معنی تومان است؛ اونس جهانی با USD/oz نمایش داده می‌شود.
- منبع، نرخ بازار آزاد تهران و اونس شاخصی است؛ قیمت قابل معاملهٔ بروکر یا نرخ رسمی بانک مرکزی نیست.
- در صورت قطع منبع، خروجی UNAVAILABLE است و قیمت ساختگی تولید نمی‌شود.
- شرایط استفادهٔ منبع: نام NerkhAra و پیوند https://nerkhara.com کنار ارقام نمایش داده شود.

## API
- سلامت: GET /health
- قیمت‌ها: GET /v1/market/quotes
- وضعیت بازار: GET /v1/market/status
- سیاست ریسک: GET /v1/risk/policy
- محاسبه حجم: POST /v1/risk/position-size
- ارزیابی تحلیل: POST /v1/signals/evaluate
- مستندات: /docs

## استقرار رایگان روی Cloudflare Workers
پوشهٔ backend از Python Workers و FastAPI استفاده می‌کند:
1. یک حساب رایگان Cloudflare بسازید: https://dash.cloudflare.com/sign-up
2. از Account API Tokens یک API Token با مجوز Edit Cloudflare Workers بسازید و Account ID را از داشبورد بردارید.
3. این دو مقدار را در GitHub → Settings → Secrets and variables → Actions → New repository secret با نام‌های `CLOUDFLARE_API_TOKEN` و `CLOUDFLARE_ACCOUNT_ID` ذخیره کنید.
4. از آن پس هر push به شاخهٔ main به‌طور خودکار تست و در صورت وجود دو secret، Worker را deploy می‌کند. آدرس نهایی `*.workers.dev` در لاگ همان اجرای GitHub Actions اعلام می‌شود.
5. برای اجرای محلی: از پوشهٔ backend دستور `uv sync --all-groups` و سپس `uv run pywrangler dev` را اجرا کنید.

پلن رایگان Workers طبق مستندات Cloudflare تا ۱۰۰٬۰۰۰ درخواست در روز دارد؛ محدودیت CPU رایگان ۱۰ میلی‌ثانیه برای هر درخواست است. سهمیه‌ها و محدودیت‌های جاری را پیش از استفادهٔ پرترافیک بررسی کنید.

## اندروید
پوشهٔ android پروژهٔ Android Studio است. خروجی Debug APK به‌وسیلهٔ GitHub Actions ساخته و به‌صورت Artifact با نام `ayyar-smart-trader-debug-apk` منتشر می‌شود. آدرس API در `android/app/build.gradle.kts` از طریق Gradle property با نام `API_BASE_URL` قابل تنظیم است؛ پس از اولین استقرار Cloudflare باید آن را با آدرس واقعی Worker تنظیم کرد.

## ساخت و آزمون خودکار
GitHub Actions تست‌های بک‌اند و ساخت APK آزمایشی Debug را اجرا می‌کند. نسخهٔ Release امضاشده پس از تنظیم امن کلید امضا ساخته خواهد شد.

## وضعیت و محدودیت‌ها
- هستهٔ بک‌اند، آداپتور منبع قیمت بدون کلید، سیاست ریسک و رابط اولیهٔ اندروید در مخزن ثبت شده‌اند.
- کد Worker برای استقرار Cloudflare آماده است؛ استقرار نهایی به ساخت حساب رایگان Cloudflare و ثبت دو secret در GitHub نیاز دارد.
- موتور تحلیل برای تولید سیگنال اجرایی به دادهٔ کندلی معتبر نیاز دارد؛ قیمت‌های snapshot ده‌دقیقه‌ای به‌تنهایی برای معاملات یک‌دقیقه‌ای کافی نیستند.
- هیچ معاملهٔ واقعی یا تضمین سودی ارائه نمی‌شود.
